# プロダクト要求仕様書（PRD）：DreamParade 公式サイト

## 1. 概要
株式会社HeartCandyが運営する芸能事務所「DreamParade」の公式Webサイト。
テレビ局・制作会社・イベント会社などのクライアントへのタレント売り込みと、
タレント志望者へのオーディション募集を主な目的とする。

## 2. ターゲットユーザー
### クライアント向け
- テレビ局・制作会社のディレクター・プロデューサー
- イベント企画会社の担当者
- 出演依頼を検討している企業担当者

### タレント志望者向け
- お笑い・俳優・アイドルを目指す志望者
- オーディション情報を探している人

## 3. デザイン方針
- 芸能事務所らしい洗練されたデザイン
- 黒・金・白をベースにしたプロフェッショナルな配色
- スマートフォン対応（レスポンシブデザイン）
- 後から内容を編集しやすい構成

## 4. ページ構成

### 4.1 トップページ
- ヒーローセクション（DreamParadeのロゴ・キャッチコピー）
- 事務所紹介（HeartCandy運営・ジャンル：お笑い・俳優・アイドル）
- タレント一覧（抜粋・詳細ページへのリンク）
- お知らせセクション
- お問い合わせボタン

### 4.2 タレント一覧ページ（/talents）
- 全タレントのカード一覧
- カテゴリフィルター（お笑い・俳優・アイドル）
- 各カードから個別ページへ遷移

### 4.3 タレント個別ページ（/talents/[id]）
- プロフィール詳細
- SNSリンク（Twitter・Instagram・TikTok）
- YouTube動画埋め込み
- 出演依頼ボタン

### 4.4 出演依頼ページ（/contact）
- 入力項目：会社名・担当者名・メールアドレス・希望タレント・依頼内容
- Formspree連携
- 送信後メッセージ表示

### 4.5 オーディション募集ページ（/audition）
- オーディション概要
- 募集ジャンル（お笑い・俳優・アイドル）
- 応募フォーム（名前・年齢・希望ジャンル・自己PR・連絡先）
- Formspree連携

## 5. 技術要件
- フレームワーク：Next.js（App Router）
- スタイリング：Tailwind CSS
- お問い合わせ：Formspree
- デプロイ：Vercel
- 後から編集しやすいよう、テキスト・URLはconstants.tsにまとめる
